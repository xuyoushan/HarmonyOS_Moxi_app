# 🌿 **墨析 · Moxi**  
以墨为始 · 析之成文  
HarmonyOS NEXT 上的 Markdown 全能工具。

---

## ✨ 功能概览（Features）

### 📖 **Markdown 阅读**
- 精准渲染：标题、目录、代码块、表格、图片  
- 护眼模式 / 字体调节 / 行高调节 / 主题切换  
- 沉浸式阅读  
- 自动记住阅读进度  
- TOC 目录跳转  
- 查找文本  

### ✍️ **Markdown 编辑**
- 实时预览  
- 一键整句加粗 / 标题 / 引用 / 列表  
- 段落拖拽排序  
- 多标签文档  
- 查找 & 替换  
- 外接键盘快捷键（平板 / PC）

### 🧹 **Markdown 清洗**
- 粘贴 → 一键清理 → 自动复制  
- 纯净模式（无格式）  
- 语义模式（标题编号 / 粗体替换）  
- 自动空行 / 自动标题层级 / 去重空格  
- 微信公众号无格式版  
- 大纲提取  
- 清洗历史记录（搜索 / 分组）

### 📤 **导出**
- 导出为纯文本  
- 导出为 Word（.doc / .docx）  
- 导出为 PDF（排版 / 页眉页脚）  
- 导出为公众号干净文本  
- 支持 FilePicker 保存到系统文件管理（API 22）

### 🤖 **AI（可选）**
- 自动排版  
- 自动空行  
- 自动标题层级  
- 文本润色  

### 🧭 **鸿蒙专属能力**
- 元服务（Widget）  
- 原子化服务（免安装编辑 / 清理）  
- 分布式流转（手机 → 平板 → PC）  
- 鸿蒙原生分享（Share 卡片）  
- 小艺语音助手指令  
- 多端数据同步（DataShare）

---

## 📱 设备适配
- 手机：单栏、底部操作条  
- 平板 / 折叠屏：左右分栏、多标签、完整工具栏
